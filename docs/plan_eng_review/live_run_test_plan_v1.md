## Purpose

这份文件给后续 `/qa`、`/qa-only` 和实现阶段测试补齐使用，目标是把“全链路 live run”拆成可验证的测试层次，而不是只做几条 happy path。

## Test strategy

```text
Layer 1: Unit
  temp / vision / curve / state_machine / config contracts

Layer 2: Integration
  live_run coordinator + fake adapters + artifact store + rate accounting

Layer 3: API Contract
  create / define / start / stop / telemetry / result / achieved-rate detail

Layer 4: Browser Flow
  preview -> definition -> run gating -> result view

Layer 5: Bench / Performance
  50 Hz measurement gate / 100 Hz stretch gate

Layer 6: Architecture
  import boundaries + no route-to-hardware leakage
```

## Temporal sampling test addendum

基于
[live_capture_temporal_sampling_requirement_v1.md](../requirements/live_capture_temporal_sampling_requirement_v1.md)，
测试计划新增 4 条强制原则：

1. `preview_display_fps` 与 `measurement_sample_hz` 不允许在测试里混为同一个断言。
2. `50 Hz` baseline 只能由真实 bench gate 声称完成。
3. API / artifact 必须验证 achieved values，而不只是 desired config。
4. browser test 负责 setup 可操作性，不负责替代 measurement cadence 验收。

## Required suites

- connect timeout
- command ack failure

- stop command on already stopped device

#### `tests/vision/test_metric_two_point_distance.py`

- ROI outside image bounds
- metric box outside ROI bounds
- dark-on-light threshold path
- adaptive threshold path
- ignore internal texture path
- farthest pair init path

#### `tests/curve/test_afas_adapter.py`

- channel extraction from `SyncPoint`
- insufficient data
- missing temperature sample
- invalid metric sample
- successful `As/Af`

#### `tests/workflow/test_live_run_state_machine.py`

- cannot start without measurement definition
- cannot start without temp controller readiness
- invalidation transition
- failed finalize transition

### 2. Integration suites

#### `tests/workflow/test_live_run.py`

Fixtures:

- fake camera with deterministic frames
- fake temp controller with deterministic temperature ramp
- fake vision extractor with deterministic `Space1`
- temp read failure fixture
- tracking invalidation fixture

Scenarios:

- completed run
- temp control failure before running
- temp read failure during running
- tracking invalidated during running
- finalize result failure

### 3. Storage suites

#### `tests/storage/test_live_run_artifacts.py`

Assert:

- session directory created
- `definition.json` written
- `telemetry.csv` written
- `events.jsonl` written
- `result.json` written
- missing artifact fails finalize

### 4. API suites

#### `tests/webapp/test_live_run_api.py`

Endpoints:

- `POST /api/runs`
- `GET /api/runs/{run_id}`
- `POST /api/runs/{run_id}/preview/frame`
- `PUT /api/runs/{run_id}/definition`

- `POST /api/runs/{run_id}/stop`
- `GET /api/runs/{run_id}/telemetry`
- `GET /api/runs/{run_id}/result`

Required assertions:

- start button gating represented in API responses
- invalid transitions return explicit errors
- telemetry payload shape stable
- result not available before finalize
- run detail exposes achieved-rate fields and `capture_mode`

### 5. Browser suites

#### `tests/webapp/test_local_visible_live_setup.py`

Visual checks:

- preview renders
- preview stop freezes the last frame instead of clearing it
- preview restart works on the same run without page refresh
- ROI form visible
- metric box controls visible
- ROI / observation-window / A-B overlays visible
- auto-detect suggestions render as visible overlay, not only form values
- definition cannot submit invalid width/height/angle
- run button disabled until definition locked
- result panel shows `As/Af` and evidence references

### 6. Performance / bench suites

#### Bench validation owner

- [live_run_bench_validation_v1.md](./live_run_bench_validation_v1.md)

Required gates:

- setup preview gate:
  - setup path no longer obviously too slow for operator use
- `50 Hz synchronized measurement` gate:
  - achieved `measurement_sample_hz >= 50`
  - achieved value is reflected in API or artifact
  - acquisition profile and exposure are recorded alongside the result
- `100 Hz` stretch gate:
  - only evaluated after the `50 Hz` gate passes

## Failure-mode matrix

| Failure | Expected state | User sees | Test owner |
| --- | --- | --- | --- |
| camera frame missing | `failed` or `preview_ready` blocked | clear error banner | webapp + workflow |
| temp controller connect fails | `device_ready` blocked | clear connect error | temp + workflow |
| target temperature command rejected | `run_ready` stays blocked | actionable error | temp + workflow |
| preview stop clears the frame instead of freezing it | `definition_editing` blocked or UX mismatch | last frame remains editable | webapp |
| preview cannot restart after stop without page refresh | `preview_ready` stuck or stale editor state | restart action works in-place | webapp |
| achieved preview fps is mistaken for measurement cadence | false pass on requirement | UI/API distinguish them clearly | webapp + workflow |
| measurement mode still uses full-frame setup profile | bench cannot reach target cadence | profile split visible and testable | camera + workflow |
| tracking quality drops briefly | `running` with warning | warning + low-confidence badge | vision + workflow |
| tracking fully lost | `invalidated` or `aborted` | stop/abort prompt | workflow |
| AFAS lacks enough valid points | `completed` with failed result | result unavailable + reason | curve + workflow |
| artifact write fails | `failed` finalize | explicit finalize error | storage + workflow |

## Ship gate

Implementation should not be considered ready unless all of the following are true:

- all unit suites pass
- integration suite covers at least one invalidation path
- API suite covers all live endpoints
- browser flow test proves freeze/restart lifecycle plus run gating
- achieved-rate reporting is covered by API and artifact assertions
- no one claims `50 Hz` complete without real-bench evidence
- no silent failure remains in failure-mode matrix
